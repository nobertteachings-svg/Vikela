# Training

**Path:** Sidebar → **Training** (`/training`)  
**Who:** Admin/Member manage modules and assignments. Members complete **My training**. Auditors typically view/completion export as allowed.

## Purpose

Security awareness training: create modules, assign to the team, track completion, issue certificates, and export CSV for auditors (e.g. SOC 2 CC1.4-style people controls).

## Navigation and primary workflows

### Admins / managers

1. Open **Training**.
2. **Create** a module: name, description, framework tag (e.g. SOC 2 CC1.4), duration, due date.
3. **Assign** to all members or selected people.
4. Track statuses: On track, At risk, Overdue, Complete, etc.
5. Send **reminders** for overdue assignments.
6. **Export completion CSV**; download **HTML certificates**.
7. Optionally **force-complete** a member row when policy allows (admin).

### Learners (My training)

1. Open assigned courses in the **course player**.
2. Complete lessons and quiz.
3. Mark complete → receive certificate.

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| No modules | Admin creates/syncs catalog; run catalog sync if operator provides one |
| Reminder failed | Check email configuration with operator |
| Certificate missing | Complete all lessons/quiz; re-download from training UI |
| Overdue stuck | Update due date or force-complete per policy |
